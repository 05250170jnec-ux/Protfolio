# Dechen Pem | Personal Portfolio

A responsive portfolio website built with HTML, CSS and JavaScript.

## Features
- Sections: Home, About Me, Skills, Projects, Education, Contact
- Cherry red dark theme with a light/dark theme toggle (choice is remembered)
- Mobile navigation menu, active-link highlighting, smooth scrolling
- Project filter by technology
- Contact form with validation (opens the visitor's email app) and a copy-email button
- Responsive on desktop, tablet and mobile

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | Styling, themes and responsive layout |
| `script.js` | Interactivity |
| `data.js` | Your projects, education and certifications (edit this file) |
| `images/profile.jpg` | Profile photo |

## Run locally
Open `index.html` in a browser. No build step is needed.

## Deploy on GitHub Pages
1. Create a new public repository on GitHub, for example `portfolio`.
2. Upload all files in this folder (keep `images/` as a folder).
3. Go to **Settings > Pages**, set **Source** to `Deploy from a branch`, choose `main` and `/ (root)`, then Save.
4. After about a minute your site is live at `https://YOUR-USERNAME.github.io/portfolio/`.
